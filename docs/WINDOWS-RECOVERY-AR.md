# إصلاح Windows غير العامل — تطوير بعد 0.8.0

تتضمن صفحة تعطل Windows خطة وتنفيذًا فعليًا لثلاث عمليات منفصلة: BCDBoot لإعادة إنشاء ملفات الإقلاع، SFC verifyonly لفحص ملفات النظام، وSFC scannow لإصلاحها. لا يحدد رمز 0xc0000001 السبب وحده.

شغّل البرنامج كمسؤول من تثبيت Windows آخر يحتوي على وحدتي PowerShell Storage وBitLocker، أو بيئة استرداد متوافقة. WinRE/WinPE القياسية قد تفتقد هاتين الوحدتين، وعندها يتوقف التنفيذ ولا يخمن هوية القرص. ركّب قسم Windows وقسم الإقلاع وحدد حروفهما، ثم حدد جذر قسم على قرص آخر للنسخ الاحتياطية. لا يفك البرنامج BitLocker؛ يلزم فك القفل أولًا بمعرفة المستخدم.

- Windows وقسم الإقلاع على القرص نفسه؛ القرص العامل وأقسامه محمية. يجب أن تكون الوجهة سليمة وقابلة للكتابة. يفضل العمل على نسخة إلى قرص سليم.
- UEFI: قسم GPT من نوع ESP وبنظام FAT32. BIOS: قسم MBR موجود ونشط وNTFS. لا تنشئ الأداة أقسامًا ولا تغير علامة active أو قطاعات MBR/VBR.
- يُعرض الأمر وهوية القرص والأقسام قبل التنفيذ. الخطة صالحة لخمس دقائق. يتطلب التنفيذ تأكيدًا مطابقًا وإقرار حفظ البيانات.
- تحفظ ملفات EFI\Microsoft\Boot وEFI\Boot أو Boot وbootmgr على قرص آخر، مع SHA-256 وقراءة تحقق. فشل النسخة الاحتياطية يمنع تشغيل أداة الإصلاح. هذه نسخة لملفات الإقلاع وليست نسخة للبيانات الشخصية أو لقرص Windows بالكامل.
- يعاد التحقق من الهوية قبل النسخ وبعده. لا يوقف البرنامج أمر إصلاح قيد الكتابة بالقوة، ولا يدعي استعادة تلقائية عند الفشل.
- BCDBoot يستخدم /s لتقييد الكتابة إلى القسم المحدد. لذلك لا ينشئ إدخال NVRAM جديدًا؛ تحتاج الإدخالات المفقودة معالجة منفصلة. UEFI Secure Boot وقواعد الإبطال المتنوعة ليست معتمدة لهذا المسار.
- تحتفظ العملية بتقرير الأدوات في tool-output.txt وسجل SFC عند توفره. completed يعني أن الأداة أعادت رمز خروج صفرًا، وليس أن الجهاز أقلع أو أن جميع التلفيات عولجت. اقرأ السجل ثم تحقق من الإقلاع فعليًا.

مثال تشغيل الأداة المرفقة من PowerShell كمسؤول بعد مراجعة الأقسام:

```powershell
$request = @{action='plan'; windowsRoot='D:\'; bootRoot='S:\'; backupRoot='E:\'; mode='UEFI'; task='bcdboot'}
$encoded = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes(($request | ConvertTo-Json -Compress)))
$review = (& .\recovery-tools\windows_recovery.ps1 -RequestBase64 $encoded) | ConvertFrom-Json
$review | ConvertTo-Json -Depth 14
# بعد مراجعة التقرير وحفظ البيانات: استخدم الواجهة لإدخال التأكيد وتنفيذ الخطة.
```

الاختبارات تشمل رفض المسارات، حماية القرص العامل، تغير الهوية، اختلاف أقراص الإقلاع/Windows، النسخ على القرص نفسه، المساحة المحدودة، نوع ESP وعلامة active وأوامر SFC/BCDBoot والنسخ مع readback. اختبارات السياسة تستخدم بيانات محاكاة وملفات مؤقتة؛ لا تثبت إقلاع Windows بعد إصلاح تثبيت تالف. هذا التأهيل وتجارب الأجهزة الفعلية ما زالا مطلوبين.
