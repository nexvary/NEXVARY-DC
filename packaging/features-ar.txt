NEXVARY DISK CARE 0.3.0
تشخيص وصيانة وإدارة وسائط التخزين

الوظائف المتاحة
• اكتشاف الأقراص وقراءة SMART بمحرك مضمّن
• الحرارة وساعات التشغيل ونسخة Firmware ومؤشرات الصحة عند دعم الجهاز
• فحص السطح بالقراءة فقط وتسجيل المقاطع غير المقروءة
• إنشاء صورة إنقاذ على قرص آخر وخريطة قراءة والتحقق من الصورة
• فحص صور الأقراص وحساب SHA-256 والنسخ مع التحقق
• اختبار كتابة وقراءة مساحة تختارها على الفلاشات والكروت
• فورمات أقسام USB / SD / MMC الخارجية: exFAT وNTFS وFAT32
• إنشاء وحذف الأقسام وإعادة التقسيم بنظام GPT أوMBR
• فحص وإصلاح نظام الملفات بواسطة خدمات Windows
• تجهيز مثبت Windows x64 UEFI من ملف ISO متوافق
• تقسيم install.wim الكبير بواسطة DISM والتحقق من الملفات المنسوخة
• سجل عمليات محلي وتصدير تقارير JSON
• واجهة عربية وإنجليزية وصفحة معلومات المطور

مراجعة الهدف قبل التنفيذ
الأقراص الداخلية وأقراص النظام محمية. تعديل الوسائط الخارجية يتطلب
صلاحيات المسؤول، وتأكيد الجهاز المستهدف، والإقرار بحفظ نسخة احتياطية.

حدود هذه النسخة
إعادة التقسيم وتجهيز الإقلاع يمسحان الوسيط المستهدف.
اختبار السعة لا يثبت السعة الأصلية الداخلية كاملة.
الإنقاذ يملأ المقاطع غير المقروءة بأصفار مع تسجيلها بدقة 1 MiB.
تحديث Firmware وإصلاح التلف المادي وإقلاع BIOS أوLinux واستعادة الملفات
المحذوفة ليست ضمن النسخة. الإقلاع وإصلاح الأقراص لم يُختبرا على أجهزة فعلية.

استعادة صور PNG وJPEG من صور الإنقاذ مع سجل وبصمات وتحقق من النسخ؛ لا تعيد الأسماء أو المجلدات الأصلية.
تجهيز Windows x64 BIOS/UEFI وكتابة صور Linux الهجينة بعد التأكيد وقفل الوسيط، والتحقق بالقراءة. الإقلاع الفعلي يحتاج تجربة.
استعادة ملفات FAT32 المحذوفة والمتصلة من صور الأقسام أو أقسام MBR الأساسية، مع التحقق من خلو الكتل وسجل وبصمات الملفات. لا يضمن سلامة محتوى سبق الكتابة فوقه.
