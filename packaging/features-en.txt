NEXVARY DISK CARE 0.3.0
Storage diagnostics and maintenance

INCLUDED FEATURES
- Physical disk discovery and bundled SMART diagnostics
- Temperature, operating hours, firmware version and health indicators when supported
- Read-only physical surface scan with unreadable-range reporting
- Best-effort disk imaging to a different disk, read map and image readback
- Image-file inspection, SHA-256 and verified copying
- Flash/card write-and-read tests over a selected size
- External USB/SD/MMC partition formatting: exFAT, NTFS, FAT32
- Create/delete partitions and rebuild GPT/MBR layouts
- Filesystem scan and repair using Windows storage services
- Windows x64 UEFI/GPT or BIOS + UEFI/MBR installation media
- Hybrid Linux ISO writing with volume locking and SHA-256 readback
- PNG/JPEG signature carving from rescue images
- Contiguous deleted FAT32 files from volume images or primary MBR partitions
- Separate recovery folders with manifests, hashes and verified file copies
- Large install.wim splitting via DISM; copied-file SHA-256 readback
- Local operation history and exportable JSON reports
- Arabic RTL / English interface and developer information

DEVICE REVIEW BEFORE EVERY STORAGE CHANGE
Internal/system disks are protected. External disk changes require administrator
permission, a target-specific confirmation and backup acknowledgement.

IMPORTANT SCOPE
GPT/MBR rebuilding and boot-media creation erase the target disk.
Capacity tests cover tested space, not exact physical NAND capacity.
Rescue records 1 MiB unreadable chunks as zeros and cannot restore those bytes.
Firmware flashing and physical surface repair are not shipped. Physical boot and
disk repair have not been hardware-tested. Linux boot support depends on its hybrid ISO.
NTFS/exFAT undelete and fragmented-file recovery are unsupported. JPEG and FAT32
candidates require content review; copy hashes do not prove original data integrity.
Original long names and folder hierarchy are not reconstructed. Limits: 64 MiB/file, 10000 files.
